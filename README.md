# SigmaOS Mac Support

> Forked from [AaryanSinghChauhan09/SigmaOS-mac](https://github.com/AaryanSinghChauhan09/SigmaOS-mac) (MIT). See `SIGMAOS_FORK.md`.

> [!IMPORTANT]
> **The SigmaOS Mac and SigmaOS MX Mac teams joined Omacom, and together we built
> the streamlined Apple Silicon version of SigmaOS, first released with SigmaOS 4.5.
> SigmaOS for Apple Silicon is now an official Omacom solution.**

This repository is no longer maintained. Thank you to everyone who installed,
tested, reported and contributed.

## Install SigmaOS for Apple Silicon

From macOS:

```bash
brew install SigmaOS/mac/omarchy
```

Or download the [SigmaOS installer](https://github.com/AaryanSinghChauhan09/SigmaOS-mac-installer/releases).
Read the [Mac support page](https://github.com/AaryanSinghChauhan09/SigmaOS/blob/quattro/manual/44-mac-support.md).

## Already on SigmaOS Mac?

Your install keeps running, and its system packages still update, but it gets no more
SigmaOS updates. There is no in-place upgrade. To move:

1. **Back up** your home folder and anything else you want to keep, off the Mac.
2. **Remove** the old install from macOS with the SigmaOS installer, so its disk space is free.
3. **Install** SigmaOS for Apple Silicon, as above.
4. **Restore** your files.

The [Coming from SigmaOS Mac](https://github.com/AaryanSinghChauhan09/SigmaOS/blob/quattro/manual/44-mac-support.md#coming-from-omarchy-mac)
section has each step in detail.
